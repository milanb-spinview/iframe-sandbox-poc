iframe sandbox demo

Each page below is served over https and meant to be embedded as another site's <iframe src>. They show what an embedded page can still do when the host <iframe> has no sandbox attribute.

  • top-nav.html — navigate the whole host page away
  • auto-top-nav.html — same, attempted on load (no click)
  • popup.html — window.open() a new tab
  • download.html — force a file into Downloads
  • form-post.html — POST to an external origin
  • spoof.html — render a fake login inside the host chrome

With sandbox on the host iframe (granting only what a real embed needs), each of these is blocked.
